What is ISOForge

ISOForge is an open source Windows CLI tool to create multiboot USB drives from ISO files.
With ISOForge, you don't need to reformat the disk every time — just copy your ISO files to the USB drive and boot them directly.
ISOForge will partition your USB, install GRUB2, and give you a boot menu to select any ISO at startup.
Both x86 Legacy BIOS and x86_64 UEFI are supported on the same drive.

Features

  • Simple Windows CLI — no GUI required
  • Boot directly from ISO files, no extraction needed
  • GRUB2 boot menu with automatic ISO detection
  • Two-partition layout: FAT32 bootloader + NTFS storage
  • x86 Legacy BIOS and x86_64 UEFI supported on the same USB
  • Both MBR and GPT partition styles supported
  • ISO files larger than 4GB supported
  • Custom GRUB theme support
  • Storage partition usable as a normal USB drive
  • No need to reformat when adding new ISOs

Installation

Follow these steps to set up ISOForge on your USB drive.

  1. Step 1 — Open ISOForge.exe as Administrator.
  2. Step 2 — Select option 1 and press Enter.
  3. Step 3 — Enter the Disk number of your USB drive, then enter Y to confirm and continue.
  4. Step 4 — Enter the drive letter assigned to the 1st partition of the USB — the partition labeled ISOFORGE.
  5. Step 5 — Open the 2nd partition of the USB — the partition labeled STORAGE.
  6. Step 6 — Create a folder for your ISO files (e.g. ISOs\) to keep things organized, then copy your ISO files into it.
Important: Do not edit or delete the boot\ and EFI\ folder on the ISOFORGE partition. It contains the GRUB2 bootloader files required to boot.

After Setup

Your USB is ready. Plug it into any computer, boot from USB, and ISOForge will show a GRUB2 menu listing all detected ISO files.

How Project Works

1. Detects connected Drivers
2. User selects which USB driver to use
3. Partitions USB into two partitions:
   - Partition 1: FAT32 (ISOFORGE) - bootloader files
   - Partition 2: NTFS (STORAGE) - ISO files, and user personal files
4. Copies boot/ and EFI/ folder to Partition 1
5. Writes boot.img to USB MBR
6. Writes core.img after MBR
7. USB is ready - User create "ISOs/" folder and copies ISO files to Partition 2

After setup, your USB drive will have two partitions with the following layout: 

USB Partition 1 (FAT32 — ISOFORGE)/
  ├── EFI/
  │    └── BOOT/
  │         └── bootx64.efi
  └── boot/
       └── grub/
            ├── grub.cfg
            ├── themes/
            │    └── isoforge/
            │         ├── theme.txt
            │         └── background.png
            ├── i386-pc/
            └── x86_64-efi/

USB Partition 2 (NTFS — STORAGE)/
  └── ISOs/
       └── (put your ISO files here)

Partition 1 — ISOFORGE (FAT32)

Contains all GRUB2 bootloader files, the EFI binary for UEFI boot, and the theme. Do not modify or delete anything here.

Partition 2 — STORAGE (NTFS)

This is where you store your ISO files. It works as a normal USB partition — you can also store personal files here alongside your ISOs.

GRUB2 Setup

ISOForge uses GRUB2 as its bootloader. The configuration is stored in boot/grub/grub.cfg on the ISOFORGE partition.

How GRUB Finds the USB

A small config called grub_early.cfg is embedded directly into core.img and bootx64.efi at build time. It tells GRUB to search for the partition labeled ISOFORGE on any computer, so the USB works regardless of which disk number it gets assigned. 

search --no-floppy --label --set=root ISOFORGE
set prefix=($root)/boot/grub
configfile ($root)/boot/grub/grub.cfg

WSL Requirements (one time)

sudo apt install grub-pc-bin grub-efi-amd64-bin xorriso mtools qemu-system-x86 -y

Generate core.img (BIOS)

Step 1 — Create grub_early.cfg

cat > ~/grub_early.cfg << 'EOF'
search --no-floppy --label --set=root ISOFORGE
set prefix=($root)/boot/grub
configfile ($root)/boot/grub/grub.cfg
EOF

Step 2 — Generate core.img

grub-mkimage -o ~/core.img -O i386-pc -p "/boot/grub" -c ~/grub_early.cfg \
  biosdisk part_msdos part_gpt fat ext2 ntfs iso9660 \
  search search_fs_file search_fs_uuid search_label \
  configfile normal linux linux16 loopback echo ls \
  reboot halt sleep test regexp \
  all_video gfxterm gfxmenu gfxterm_background video video_fb png jpeg

Step 3 — Copy to project folder

cp ~/core.img /mnt/c/Projects/Python/ISOForge\ Bootloader/boot/grub/i386-pc/

Generate bootx64.efi (UEFI)

grub-mkimage -o ~/bootx64.efi -O x86_64-efi -p "/boot/grub" -c ~/grub_early.cfg \
  part_msdos part_gpt fat ext2 ntfs iso9660 \
  search search_fs_file search_fs_uuid search_label \
  configfile normal linux linux16 loopback echo ls \
  reboot halt sleep test regexp \
  all_video gfxterm gfxmenu gfxterm_background video video_fb png jpeg

cp ~/bootx64.efi /mnt/c/Projects/Python/ISOForge\ Bootloader/EFI/boot/

Build from Source

These steps are for developers who want to regenerate the bootloader binaries or package the exe themselves. Requires WSL (Windows Subsystem for Linux).

Test with QEMU

# Copy boot folder to WSL
cp -r /mnt/c/Projects/Python/ISOForge\ Bootloader/boot ~/isoforge/

# Generate ISO
sudo grub-mkrescue -o ~/isoforge.iso ~/isoforge/

# Copy ISO back to Windows
cp ~/isoforge.iso /mnt/c/Projects/Python/ISOForge\ Bootloader/

# Run in QEMU
qemu-system-x86_64 -cdrom /mnt/c/Projects/Python/ISOForge\ Bootloader/isoforge.iso -boot d -m 512

Package as .exe (PyInstaller)

Step 1 — Install PyInstaller

py -m pip install pyinstaller

Step 2 — Build

py -m PyInstaller --onedir --add-data "boot;boot" --add-data "EFI;EFI" --name "ISOForge" main.py
Note: The .exe will be in dist/ISOForge/. Manually copy the boot/ and EFI/ folders into that directory alongside the executable.
